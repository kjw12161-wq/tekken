스프라이트 시트 조립

프레임 키 이름으로 저장한 이미지들(idle0.png, straight4.png …)을 아래에 끌어다 놓으면 게임 규격에 맞춰 크기·위치를 자동으로 맞추고 시트와 sprites.json 을 만들어 줍니다. 각 칸에는 내장 스프라이트가 반투명 가이드로 깔려 있어 자세와 정렬을 눈으로 비교할 수 있습니다. 등록하지 않은 프레임은 게임에서 내장 스프라이트가 그대로 쓰입니다.

정렬 방법 · 칸을 클릭해 선택한 뒤 방향키로 1px, Shift+방향키로 8px 이동합니다. + / − 키로 크기를 조절하고, 0 으로 자동 정렬을 되돌립니다.
프레임 낱장 PNG 를 끌어다 놓으세요 (여러 장 한 번에 가능) · 또는 클릭해서 선택
격자로 된 스프라이트 시트 한 장을 여기에 넣으면 자동으로 잘라 줍니다 · 체크무늬 배경과 격자선도 제거합니다
