스프라이트 시트 조립

프레임 키 이름으로 저장한 이미지들(idle0.png, straight4.png …)을 아래에 끌어다 놓으면 게임 규격에 맞춰 크기·위치를 자동으로 맞추고 시트와 sprites.json 을 만들어 줍니다. 각 칸에는 내장 스프라이트가 반투명 가이드로 깔려 있어 자세와 정렬을 눈으로 비교할 수 있습니다. 프롬프트는 docs/SPRITE-PROMPTS.md 를 참고하세요.

정렬 방법 · 칸을 클릭해 선택한 뒤 방향키로 1px, Shift+방향키로 8px 이동합니다. + / − 키로 크기를 조절하고, 0 으로 자동 정렬을 되돌립니다.
