# 🐉 DRAGON FIGHTER Z

철권 같은 대전 격투 게임을 드래곤볼 세계관으로 옮긴 **브라우저 2D 대전 격투 게임**입니다.
외부 라이브러리·이미지 리소스 없이 순수 HTML / CSS / JavaScript + Canvas 2D 만으로 동작합니다.

![made with](https://img.shields.io/badge/made%20with-vanilla%20JS-f7df1e) ![no build](https://img.shields.io/badge/build-none-brightgreen)

## 바로 실행하기

```bash
git clone <this repo>
cd tekken
# 아무 정적 서버나 사용하거나, index.html 을 브라우저로 열면 끝
npx http-server -p 8080 .
```

`index.html` 을 더블클릭해서 열어도 그대로 동작합니다. (빌드 과정 없음)

## 배포

**GitHub Pages** — `.github/workflows/deploy-pages.yml` 이 기본 브랜치에 푸시될 때마다 저장소를 그대로 배포합니다.
처음 한 번은 저장소 설정에서 Pages 를 켜야 합니다:
**Settings → Pages → Build and deployment → Source 를 `GitHub Actions` 로 선택.**
그 뒤 Actions 탭에서 워크플로를 재실행하면 `https://<사용자>.github.io/tekken/` 에 게시됩니다.

**단일 파일** — 어디에나 올릴 수 있는 파일 하나로 묶으려면:

```bash
node tools/build-single.js      # dist/index.html (약 270KB, CSS·JS 전부 포함)
```

정적 호스팅이 필요 없다면 이 파일 하나만 열어도 게임이 그대로 돌아갑니다.

## 게임 특징

- **19인의 전사** — 손오공 · 베지터 · 피콜로 · 프리저 · 셀 · 얼티밋 오반 · 트랭크스 · 브로리 · 쿠우라 · 초2 오반 · 초2 오공 · 초2 베지터 · 베지트 · 초오지터 · 키드 부우 · 오천크스 · 인조인간 17호 · 인조인간 18호 · 쟈넨바.
  체력 / 공격력 / 스피드 / 방어력과 전용 필살기가 각각 다르고, **오천크스는 어린아이 체형**이라 몸도 판정 상자도 작습니다.
  **인조인간 두 명은 동력이 무한**이라 기를 모으지 않아도 기 게이지가 저절로 차오릅니다.
- **3판 2선승 라운드제** — 99초 타이머, 시간 종료 시 체력 판정승, K.O. 연출과 슬로모션. 무승부가 이어져도 5라운드에서 판정으로 끝납니다.
- **격투 게임다운 시스템** — 프레임 단위(60FPS) 발동/지속/후딜 데이터, 히트스턴·가드스턴, 히트스톱, 콤보 보정, 넉다운과 기상 무적, 14프레임 입력 버퍼.
- **상·하단 이지선다** — 하단기는 앉아 가드로만, 점프 공격은 서서 가드로만 막힙니다. 잡기는 가드 불가.
- **공중 콤보** — 승룡 어퍼로 띄운 뒤 점프 캔슬로 추격. 2단 점프 1회 · 공중기 3회, 저글은 4회까지만 떠오르고 `↓ + 강` 내려찍기로 마무리합니다.
- **기(氣) 게이지** — 공격·피격·기 모으기로 충전. 기탄(15) / 빔 필살기(40) / 초필살기(100) / 변신(50)에 사용합니다.
- **기 충돌** — 기탄끼리 만나면 접점에서 버티다 위력이 센 쪽만 뚫고 나가고, 빔 필살기끼리 마주치면 **힘겨루기**가 시작됩니다. 버튼을 연타해 접점을 밀어내세요. 날아오는 기탄은 상대 빔에 닿으면 증발합니다.
- **수동 변신** — 기 50 이상 · 지상 · 경직이 아닐 때 변신키로 발동. 13초간 공격력 +18% / 이동속도 +8%, 발동 순간 무적과 충격파.
  **변신 형태가 있는 캐릭터만** 쓸 수 있습니다 — 손오공 · 베지터 · 피콜로 · 트랭크스(→ 초사이어인), 초2 오공 · 오천크스(→ **초사이어인 3**, 머리 모양과 눈썹까지 바뀝니다),
  초2 베지터(→ **마인 베지터**, 이마에 M 각인과 붉은 눈), 베지트(→ 초 베지트).
  이미 최종 형태인 얼티밋 오반 · 프리저 · 셀 · 브로리 · 쿠우라 · 초2 오반 · 초오지터 · 키드 부우 · 인조인간 17호 · 18호 · 쟈넨바는 대신 기본 성능이 높습니다.
- **빔형 / 구체형 / 참격형 필살기** — 원작에서 빔인 기술은 관통 광선으로, 구체를 던지는 기술(이레이저 캐논 · 기간틱 미티어 · 데스 볼 · 슈퍼노바)은 거대한 에너지 구체로 나갑니다. 구체는 상대 빔에 지워지지 않고 뚫고 나갑니다.
- **참격 초필살기** — 베지트의 **스피릿 소드**와 쟈넨바의 **환영 분쇄**는 기를 검으로 벼려 하늘로 솟아오른 뒤, 내리그어 지면을 통째로 갈라 버립니다. 화면 폭 대부분을 덮는 광역 참격이라 가드해도 칩 대미지가 큽니다.
- **캐릭터별 전투 스타일** — 같은 기술도 캐릭터마다 동작이 다릅니다. 정통 무술(오공) · 팔꿈치와 무릎(베지터) · 긴 리치(피콜로) · 꼬리 채찍(프리저) · 육중한 해머(셀) · 교과서적 타격(오반) · 검술(트랭크스) · 라리아트와 태클(브로리) · 손날과 팔 가시(쿠우라) ·
  분노의 관통 연타(초2 오반) · 초고속 정권(초2 오공) · 왕자의 무자비한 근접전(초2 베지터) · 필살기 말고는 발차기밖에 쓰지 않는 각술(베지트) · 크고 무거운 대회전(초오지터) ·
  고무처럼 늘어나는 팔다리(키드 부우) · 요란한 곡예 격투(오천크스) · 무심하고 정확한 타격(17호) · 백스핀과 손날의 속공(18호) · 통상기를 전부 기 검으로 베는 마검술(쟈넨바).
- **등장 / 승리 모션** — 19인 모두 다릅니다. 하늘에서 낙하, 공중 가부좌 명상, 유유히 떠서 다가오기, 검을 뽑아 베기, 분노로 기를 터뜨리며 일어서기, 장갑을 당겨 끼우기, 퓨전 포즈, 목을 꺾으며 광소하기, 손가락 V 자, 주머니에 손 넣고 어슬렁 걸어오기, 머리카락 쓸어 넘기기, 공간을 찢고 걸어 나오기 등.
- **CPU AI 4단계** — 쉬움 / 보통 / 어려움 / 초사이어인. 거리 판단, 가드 반응, 대공 요격, 기탄 견제, 초필살기 마무리를 수행합니다.
- **2인 로컬 대전** — 한 키보드에서 1P vs 2P.
- **SD 도트 스프라이트** — 머리가 크고 팔다리가 짧은 SD(치비) 비율에 큰 눈의 애니 얼굴, 부위마다 두른 외곽선, 3단계 셀 음영으로 그립니다. 스프라이트 해상도로 래스터화한 뒤 알파 스냅(반투명 가장자리 정리) · 8방향 외곽선 · 방향광 음영을 입혀 아틀라스로 굽고(캐릭터당 108프레임) 그 프레임을 찍어 그립니다. 이미지 파일은 여전히 0개입니다.
- **스프라이트 시트 교체 가능** — `assets/` 에 시트를 넣으면 내장 스프라이트 대신 사용됩니다. 프레임 단위로 섞어 쓸 수 있습니다.
- **절차적 작화** — 이펙트·배경도 모두 코드로 그립니다. 효과음 역시 WebAudio 로 실시간 합성합니다.
- **화면 자동 맞춤** — 캔버스 해상도와 보이는 월드 영역을 화면 비율에 맞춰 실시간으로 다시 계산합니다.
  가로가 넓으면 스테이지를 더 넓게 보여주고, 세로 화면에서는 게임 화면과 조작부를 위아래로 나눕니다.
  회전·창 크기 변경·전체 화면 전환에 모두 즉시 반응하며, HUD 는 컨테이너 쿼리로 게임 화면 크기에 맞춰 확대·축소됩니다.
- **모바일 지원** — 터치 기기에서는 가상 패드가 자동으로 표시되고, 전체 화면 버튼(⤢)으로 가로 고정 전체 화면에 들어갈 수 있습니다.

## 조작

| 동작 | 1P | 2P |
|---|---|---|
| 이동 | `A` `D` | `←` `→` |
| 점프 / 앉기 | `W` / `S` | `↑` / `↓` |
| 약 · 강 · 킥 | `J` `K` `L` | `1` `2` `3` |
| 기탄 | `U` | `4` |
| 빔 필살기 | `S` + `U` | `↓` + `4` |
| 초필살기 | `I` | `5` |
| 기 모으기 | `Space` | `0` |
| 변신 | `O` | `7` |
| 가드 | 뒤로 이동 (또는 `H`) | 뒤로 이동 (또는 `6`) |
| 대시 | 같은 방향 두 번 | 같은 방향 두 번 |
| 잡기 | `J` + `K` 동시 | `1` + `2` 동시 |
| 일시정지 | `Esc` | |

앉은 상태에서 강(`K`)은 **승룡 어퍼**(대공기), 킥(`L`)은 **다리 후리기**(다운)로 바뀝니다.
공중에서 `↓` + 강은 **공중 내려찍기**(강제 다운)입니다. 터치 조작은 1P 전용이며, 2P 대전은 키보드로 즐길 수 있습니다.

## 기술 구조

```
index.html          화면 구성 (타이틀 / 캐릭터 선택 / HUD / 결과 / 도움말)
css/style.css       UI · HUD · 반응형 · 터치 패드 스타일
js/util.js          수학 헬퍼, WebAudio 효과음 합성, 파티클 시스템
js/characters.js    캐릭터 스탯 / 색상 / 필살기 데이터
js/moves.js         기술 프레임 데이터(발동·지속·후딜·데미지·판정 레벨)
js/input.js         키보드 + 터치 가상 패드 입력
js/fighter.js       파이터 상태머신, 물리, 히트/허트박스, 피격 처리
js/ai.js            사람/CPU 컨트롤러 (동일 인터페이스)
js/render.js        절차적 캐릭터 작화, 오라·빔·기탄, 스테이지 렌더링
js/sprites.js       포즈 → 스프라이트 아틀라스 굽기 / 외부 시트 로딩
js/game.js          게임 루프(고정 60FPS), 라운드 진행, 충돌·힘겨루기 판정, HUD
```

- 컨트롤러가 `held(action)` / `pressed(action)` 인터페이스로 추상화되어 있어, 사람과 CPU가 완전히 동일한 규칙으로 캐릭터를 조작합니다.
- 게임 로직은 고정 타임스텝(1/60초) 누적 방식으로 갱신되므로 모니터 주사율과 무관하게 동일한 속도로 진행됩니다.
- `?debug=1` 쿼리를 붙이면 히트박스 / 허트박스 / 빔 판정이 화면에 표시되고, `?vector=1` 은 스프라이트를 끄고 벡터 렌더링으로 되돌립니다.

## 스프라이트 파이프라인

1. `poseFor()` 가 캐릭터 상태를 **정수 프레임으로 양자화된 포즈**와 프레임 키(`walk3`, `jab2`, `beamF` …)로 바꿉니다.
2. `SpriteBank` 가 그 키를 처음 만나면 리그를 0.75배 해상도로 그린 뒤
   **알파 스냅**(반투명 가장자리를 잘라 도트를 또렷하게) → **8방향 외곽선** → **위에서 내려오는 셀 음영**
   순서로 다듬어 1024×1024 아틀라스 페이지에 굽습니다(지연 생성, 캐릭터당 108프레임, 최대 10페이지).
   팔다리는 외곽선·그림자·기본·하이라이트로, 얼굴은 흰자·눈동자·눈 하이라이트·눈썹·코·입까지 그려 넣습니다.
   부위마다 자체 외곽선을 둘러 팔다리가 몸통과 겹쳐도 형태가 또렷하게 읽힙니다.
3. 이후 프레임은 아틀라스에서 잘라 그대로 찍습니다. 카메라와 캐릭터 좌표는 스프라이트 픽셀 격자에 스냅되고,
   월드 확대율(1.5) × 스프라이트 확대율(4/3) = 정확히 2배라 픽셀이 뭉개지지 않습니다.
4. `assets/sprites.json` 이 있으면 해당 프레임은 외부 시트에서 가져옵니다(없는 프레임만 내장 스프라이트 사용).

직접 그린 시트를 넣는 방법과 프레임 키 전체 목록은 [`assets/README.md`](assets/README.md) 에 정리해 두었습니다.

### 내 그림으로 교체하는 두 가지 방법

1. **덮어 그리기** — `tools/export-sprites.html` 로 현재 스프라이트를 PNG 시트로 뽑아
   도트 편집기에서 그 위에 덮어 그립니다. 규격이 이미 맞으므로 그대로 `assets/` 에 넣으면 됩니다.
2. **이미지 생성 AI** — `tools/prompt-maker.html` 에서 캐릭터·화풍·프레임을 고르면
   게임 규격(오른쪽 방향, 투명 배경, 발끝 지면선, 이펙트 금지 등)이 자동으로 들어간 프롬프트가 만들어집니다.
   108장 전 프레임을 다루며, 필살기 자세·등장 모션·승리 포즈는 **캐릭터마다 실제 동작에 맞춘 설명**이 붙습니다.
   각 프레임 옆에는 내장 스프라이트가 **포즈 레퍼런스**로 붙어 있어 그림과 함께 첨부할 수 있고,
   프레임별 **완료 체크와 진행률**이 브라우저에 저장되어 며칠에 걸쳐 나눠 작업할 수 있습니다.
3. **조립** — 생성한 그림을 `tools/pack-sprites.html` 에 넣으면 크기·위치를 자동 정렬해
   시트와 `sprites.json` 을 만들어 줍니다. 격자로 된 시트 한 장을 통째로 넣어 자동 분할할 수도 있습니다.
   작업 내용은 브라우저에 자동 저장되고(되돌리기·좌우 뒤집기·프레임 삭제 지원),
   **움직임 미리보기**로 실제로 이어 붙였을 때 발이 흔들리는지 바로 확인할 수 있습니다.
   이미 만든 `sprites.json` + 시트를 다시 불러와 이어서 고칠 수도 있습니다.
   (20장 정도만 만들어도 나머지는 내장 스프라이트로 자동 대체되어 바로 플레이할 수 있습니다.)
