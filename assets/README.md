# 스프라이트 시트 넣는 법

이 폴더에 스프라이트 시트를 넣으면 게임이 **내장(코드로 굽는) 스프라이트 대신 그 시트를 사용**합니다.
직접 도트를 찍었거나, 사용 권리를 가진 시트를 그대로 끼워 넣을 수 있습니다.

> ⚠️ 원작 게임에서 추출한 드래곤볼 스프라이트는 토에이 애니메이션·반다이남코 등의 저작물입니다.
> 개인적으로 시험해보는 것과 배포하는 것은 다릅니다. 공개 저장소·웹사이트에 올릴 시트는
> 직접 그렸거나 재배포가 허용된 것만 사용하세요. (그래서 이 저장소에는 시트가 들어 있지 않습니다)

## 1. 시작용 시트 뽑기

`tools/export-sprites.html` 을 브라우저로 열고 **[시트 만들기]** 를 누르면
캐릭터별 PNG 시트와 `sprites.json` 을 내려받을 수 있습니다.
게임이 실제로 쓰는 프레임이 그대로 들어 있으므로, 이 PNG 를 도트 편집기(Aseprite, Piskel 등)에서
덮어 그리는 방식이 가장 빠릅니다. **셀 크기와 셀 안에서의 위치(원점)는 그대로 두세요.**

## 2. 파일 배치

```
assets/
  sprites.json     ← 시트 목록과 프레임 좌표
  goku.png
  vegeta.png
  ...
```

## 3. sprites.json 형식

```json
{
  "cellWidth": 136,      // 셀 한 칸의 가로 픽셀
  "cellHeight": 150,     // 셀 한 칸의 세로 픽셀
  "originX": 50,         // 셀 안에서 캐릭터의 발끝 x
  "originY": 138,        // 셀 안에서 캐릭터의 발끝 y (이 점이 지면에 닿습니다)
  "scale": 0.75,         // 스프라이트 1px = 월드 1/0.75 단위. 캐릭터 키가 약 114px 이면 0.75
  "characters": {
    "goku": {
      "image": "goku.png",
      "frames": {
        "idle0": [0, 0],
        "idle1": [108, 0],
        "jab2":  [216, 0]
      }
    }
  }
}
```

- `frames` 는 **프레임 키 → 시트 안의 [x, y]** 입니다.
- 등록하지 않은 프레임은 자동으로 내장 스프라이트가 사용됩니다. 한 캐릭터만, 몇 동작만 교체해도 됩니다.
- 캐릭터별로 `"meta": { "cellWidth": ..., "scale": ... }` 를 넣어 개별 규격을 쓸 수도 있습니다.
- 손오공·베지터·트랭크스는 기 게이지가 가득 차면 초사이어인이 됩니다.
  `"jab2_ss"` 처럼 키 뒤에 `_ss` 를 붙인 프레임이 있으면 그때 그 프레임을 사용합니다.

## 4. 프레임 키 목록 (총 88장)

| 분류 | 키 |
|---|---|
| 대기 | `idle0` ~ `idle3` |
| 전진 / 후진 | `walk0` ~ `walk5` / `back0` ~ `back5` |
| 기 모으기 | `charge0` ~ `charge3` |
| 승리 포즈 | `win0` ~ `win3` |
| 자세 | `crouch`, `crouchGuard`, `guard`, `dash`, `wakeup`, `down`, `hurt` |
| 점프 | `jumpUp`(상승), `jumpDown`(하강) |
| 타격기 | `jab0~4`, `straight0~4`, `roundhouse0~4`, `lowKick0~4`, `sweep0~4`, `uppercut0~4`, `grab0~4` |
| 공중기 | `airPunch0~4`, `airKick0~4` |
| 기탄 | `kiBlast0~4` |
| 빔 필살기 | `beamC0` ~ `beamC3`(모으기), `beamF`(발사) |

숫자는 동작의 진행 단계입니다. `0` 이 시작 자세, `4` 가 기술이 완전히 뻗은 순간이며
후딜에는 같은 프레임이 역순으로 재생됩니다. 초필살기는 빔 필살기와 같은 프레임(`beamC*`, `beamF`)을 씁니다.

## 5. 확인

- 게임을 `?debug=1` 로 열면 판정 박스가 보입니다. 스프라이트가 박스와 크게 어긋나면
  `originX` / `originY` / `scale` 을 조정하세요.
- `?vector=1` 로 열면 스프라이트를 끄고 원래 벡터 렌더링으로 비교할 수 있습니다.
