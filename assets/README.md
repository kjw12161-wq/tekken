# 스프라이트 시트 넣는 법

이 폴더에 스프라이트 시트를 넣으면 게임이 **내장(코드로 굽는) 스프라이트 대신 그 시트를 사용**합니다.
직접 도트를 찍었거나, 사용 권리를 가진 시트를 그대로 끼워 넣을 수 있습니다.

> ⚠️ 원작 게임에서 추출한 드래곤볼 스프라이트는 토에이 애니메이션·반다이남코 등의 저작물입니다.
> 개인적으로 시험해보는 것과 배포하는 것은 다릅니다. 공개 저장소·웹사이트에 올릴 시트는
> 직접 그렸거나 재배포가 허용된 것만 사용하세요. (그래서 이 저장소에는 시트가 들어 있지 않습니다)

## 0. 이미지 생성 AI 로 만들 때

`tools/prompt-maker.html` 에서 캐릭터·화풍·프레임을 고르면 게임 규격이 들어간 프롬프트와
포즈 레퍼런스 이미지를 얻을 수 있습니다. 생성한 그림은 아래 방법으로 조립하면 됩니다.

## 1. 프레임을 한 장씩 그렸다면

프레임 키 이름(`idle0.png`, `straight4.png` …)으로 저장한 뒤 `tools/pack-sprites.html` 에
끌어다 놓으면 크기·위치가 자동 정렬되고 시트와 `sprites.json` 이 만들어집니다.

## 2. 시작용 시트 뽑기

`tools/export-sprites.html` 을 브라우저로 열고 **[시트 만들기]** 를 누르면
캐릭터별 PNG 시트와 `sprites.json` 을 내려받을 수 있습니다.
게임이 실제로 쓰는 프레임이 그대로 들어 있으므로, 이 PNG 를 도트 편집기(Aseprite, Piskel 등)에서
덮어 그리는 방식이 가장 빠릅니다. **셀 크기와 셀 안에서의 위치(원점)는 그대로 두세요.**

## 3. 파일 배치

```
assets/
  sprites.json     ← 시트 목록과 프레임 좌표
  goku.png
  vegeta.png
  ...
```

## 4. sprites.json 형식

```json
{
  "cellWidth": 136,      // 셀 한 칸의 가로 픽셀
  "cellHeight": 168,     // 셀 한 칸의 세로 픽셀
  "originX": 50,         // 셀 안에서 캐릭터의 발끝 x
  "originY": 154,        // 셀 안에서 캐릭터의 발끝 y (이 점이 지면에 닿습니다)
  "scale": 0.75,         // 스프라이트 1px = 월드 1/0.75 단위. 캐릭터 키가 약 105px(머리카락 포함 130px) 이면 0.75
  "characters": {
    "goku": {
      "image": "goku.png",
      "frames": {
        "idle0": [0, 0],
        "idle1": [108, 0],
        "jab2":  [216, 0]
      }
    }
  }
}
```

- `frames` 는 **프레임 키 → 시트 안의 [x, y]** 입니다.
- 등록하지 않은 프레임은 자동으로 내장 스프라이트가 사용됩니다. 한 캐릭터만, 몇 동작만 교체해도 됩니다.
- 캐릭터별로 `"meta": { "cellWidth": ..., "scale": ... }` 를 넣어 개별 규격을 쓸 수도 있습니다.
- 손오공·베지터·트랭크스는 기 게이지가 가득 차면 초사이어인이 됩니다.
  `"jab2_ss"` 처럼 키 뒤에 `_ss` 를 붙인 프레임이 있으면 **변신(초사이어인) 중에** 그 프레임을 사용합니다.
  변신은 기 50 이상일 때 변신키로 직접 발동합니다.

## 5. 프레임 키 목록 (총 108장)

| 분류 | 키 |
|---|---|
| 대기 | `idle0` ~ `idle3` |
| 전진 / 후진 | `walk0` ~ `walk5` / `back0` ~ `back5` |
| 기 모으기 | `charge0` ~ `charge3` |
| 승리 포즈 | `win0` ~ `win3` (캐릭터마다 다른 자세) |
| 등장 모션 | `ent0` ~ `ent7` (캐릭터마다 다른 연출, 진행 순서대로) |
| 자세 | `crouch`, `crouchGuard`, `guard`, `dash`, `wakeup`, `down`, `hurt` |
| 점프 | `jumpUp`(상승), `jumpDown`(하강) |
| 타격기 | `jab0~4`, `straight0~4`, `roundhouse0~4`, `lowKick0~4`, `sweep0~4`, `uppercut0~4`, `grab0~4` |
| 공중기 | `airPunch0~4`, `airKick0~4`, `airSlam0~4`(↓+강 내려찍기) |
| 기탄 | `kiBlast0~4` |
| 빔 필살기 | `beamC0` ~ `beamC4`(모으기), `beamF`(발사) |
| 초필살기 | `ultC0` ~ `ultC4`(모으기), `ultF`(발사) |

숫자는 동작의 진행 단계입니다. `0` 이 시작 자세, `4` 가 기술이 완전히 뻗은 순간이며
후딜에는 같은 프레임이 역순으로 재생됩니다.

필살기와 초필살기는 캐릭터마다 자세가 다르므로 프레임을 따로 씁니다
(`beamC*`/`beamF` = 필살기, `ultC*`/`ultF` = 초필살기).
어떤 자세를 그려야 하는지는 캐릭터의 모션 종류(`js/moves.js` 의 `SPECIAL_MOTION`)를 따릅니다.

| 모션 | 자세 | 쓰는 캐릭터 |
|---|---|---|
| `cupped` | 허리 뒤에 두 손을 모았다가 정면으로 (에네르기파) | 손오공, 셀 |
| `onehand` | 옆구리에 모은 한 손을 뻗고 반대 손으로 손목을 받침 (갤릭포) | 베지터(필살기) |
| `flash` | 양팔을 크게 벌려 모았다가 정면으로 합침 (파이널 플래시) | 베지터(초필살기) |
| `fingers` | 두 손가락을 이마에 붙이고 반대 손으로 팔꿈치를 받침 (마관광살포) | 피콜로(필살기) |
| `wave` | 팔을 높이 들어 모았다가 두 손으로 밀어냄 (초 폭렬마파) | 피콜로(초필살기) |
| `point` | 손가락 하나만 세운 여유로운 자세 (데스 빔) | 프리저(필살기) |
| `orb` | 머리 위로 구슬을 들었다가 내려꽂음 (데스 볼) | 프리저(초필살기), 트랭크스(초필살기) |
| `overhead` | 머리 위에서 손목을 교차했다가 앞으로 밀어냄 (마섬광) | 얼티밋 오반 |
| `weave` | 손을 교차해 빠르게 감았다가 양손을 앞으로 (버닝 어택) | 트랭크스(필살기) |
| `palm` | 한 손바닥을 앞으로 내밀어 굵은 광선 (이레이저 캐논) | 브로리(필살기) |
| `twinOrb` | 두 손을 머리 위로 모아 거대한 구체 (기간틱 미티어) | 브로리(초필살기) |

### 등장 / 승리 모션

캐릭터마다 입장·승리 연출이 다릅니다. `ent0`~`ent7` 은 등장 연출을 8단계로 나눈 것이고,
`win0`~`win3` 은 승리 자세의 4프레임 루프입니다. 아래 표대로 그리면 게임 연출과 맞습니다.
(하늘에서 내려오거나 떠서 다가오는 이동은 코드가 처리하므로, 그림은 자세만 그리면 됩니다)

| 캐릭터 | 등장 (`ent0~7`) | 승리 (`win0~3`) |
|---|---|---|
| 손오공 | 하늘에서 낙하 → 착지 → 주먹을 맞부딪히고 자세 | 뒷머리를 긁으며 웃는다 |
| 베지터 | 팔짱을 끼고 내려다보다 기를 올리며 자세 | 팔짱을 높이 끼고 고개를 돌린다 |
| 피콜로 | 공중 가부좌 명상 → 내려서며 팔짱을 풀고 자세 | 팔짱을 낮게 끼고 눈을 감는다 |
| 프리저 | 팔짱을 끼고 유유히 떠서 다가와 손짓으로 도발 | 손가락을 들어 바라본다 |
| 셀 | 어깨를 으쓱 → 두 팔을 크게 벌리고 자세 | 두 팔을 벌려 젖히고 웃는다 |
| 얼티밋 오반 | 손을 내리고 서 있다 기를 끌어올리며 자세 | 주먹을 하늘로 뻗는다 |
| 트랭크스 | 등 뒤에서 검을 뽑아 크게 베어 내리고 자세 | 검을 어깨에 걸친 자세 |
| 브로리 | 고개를 숙이고 있다가 포효하며 기를 폭발 | 두 주먹을 하늘로 치켜들고 포효 |
| 쿠우라 | 팔짱을 낀 채 급강하해 착지, 꼬리를 크게 휘두름 | 어깨를 툭툭 털며 내려다본다 |

### 캐릭터 디자인 / 전투 스타일

원작 디자인을 참고해 색과 부위를 정리했습니다. 스프라이트를 직접 그릴 때 이 색을 쓰면 게임과 어울립니다.

| 캐릭터 | 디자인 요점 | 고유 부위 | 전투 스타일 |
|---|---|---|---|
| 손오공 | 주황 도복 · 파란 띠/손목밴드 | – | `karate` 정통 무술 (허리에 감은 정권, 높은 돌려차기) |
| 베지터 | 감청 슈트 · 흰 장갑/부츠 · 금색 벨트 | 전투복 갑주 | `royal` 팔꿈치와 무릎 (백너클, 니킥, 라이징 엘보) |
| 피콜로 | 보라 도복 · 흰 터번 · 초록 피부 | 안테나 | `demon` 긴 리치 (손날 찌르기, 손바닥 밀치기, 긴 후리기) |
| 프리저 | 흰 생체 장갑 · 보라 보석(머리·어깨·가슴·정강이) · 붉은 눈 | **꼬리** | `emperor` 우아하고 잔인 (손등 치기, 꼬리 채찍/후리기, 니킥) |
| 셀 | 검은 상체 · 크림색 가슴판 · 초록 팔다리에 검은 점 · 금색 부츠 | **날개**, 점박이 | `perfect` 육중 (해머 내리찍기, 스톰프, 양손 쳐올리기) |
| 얼티밋 오반 | 감청 도복 · 하늘색 속옷 · 붉은 띠 | – | `mystic` 교과서적 (반대주먹 정권, 뒤후려차기, 장저) |
| 트랭크스 | 보라 재킷 · 검은 속옷/바지 · 금색 벨트/부츠 · 하늘색 검대 | **검**, 칼집 | `blade` 검술 (모든 타격이 베기) |
| 브로리 | 맨몸 상체 · 연둣빛 금발 · 붉은 허리천 · 금색 목걸이/손목보호대/부츠 | **허리천**, 목걸이, 큰 체구(bulk 1.24) | `legendary` 파워 (라리아트, 어깨 태클, 양손 해머) |
| 쿠우라 | 보라 몸통 · 흰 갑주와 뿔 · 파란 보석 · 얼굴 가면 | **꼬리**, 팔꿈치 가시, 가면 | `cooler` 속공 (손날, 팔 가시 찌르기, 회전 뒤차기, 꼬리 쓸기) |

꼬리·날개·검은 코드가 포즈에 맞춰 따로 그리므로, 시트를 그릴 때는 몸만 그려도 됩니다.
직접 그린 시트로 완전히 대체하고 싶다면 해당 캐릭터의 `props` 를 지우면 됩니다.

## 6. 확인

- 게임을 `?debug=1` 로 열면 판정 박스가 보입니다. 스프라이트가 박스와 크게 어긋나면
  `originX` / `originY` / `scale` 을 조정하세요.
- `?vector=1` 로 열면 스프라이트를 끄고 원래 벡터 렌더링으로 비교할 수 있습니다.
